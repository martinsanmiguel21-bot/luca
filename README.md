# Luca 🫙

App para controlar tu mesada: anota gastos en dos toques, mira cuánto puedes gastar por día y junta para tu meta.

Funciona en el navegador y se puede instalar en el celular. Los datos se guardan solo en tu dispositivo.

## Cómo publicarla en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `luca`), público.
2. Toca **Add file → Upload files** y sube todos los archivos de esta carpeta (no la carpeta, sino lo que está dentro). Toca **Commit changes**.
3. Ve a **Settings → Pages**. En "Source" elige **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guarda.
4. Espera uno o dos minutos. Tu app quedará en `https://TU-USUARIO.github.io/luca/`.
5. Ábrela en el celular y ponla en tu pantalla de inicio (Ajustes → "Poner Luca en mi pantalla de inicio" explica cómo).

La política de privacidad queda en `https://TU-USUARIO.github.io/luca/privacidad.html` (sirve también para la App Store).

## Para actualizarla
Sube el archivo nuevo con el mismo nombre. Si cambias `index.html`, cambia también `luca-v1` por `luca-v2` en `sw.js` para que los celulares descarguen la versión nueva.
